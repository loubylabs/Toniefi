    myTonies account

    Used to sign in to the Tonie Cloud so Toniefi can list your Creative Tonies and upload to them. Setting TONIES_USERNAME and TONIES_PASSWORD as environment variables is preferable — credentials saved here are stored in plain text in the app's SQLite database. Two-factor accounts will not work with this login method.

    About

    Toniefi talks to the private API behind the myTonies web app. It is not an official or supported interface and this project is not affiliated with tonies / Boxine. If an upload starts failing, the API most likely changed — your library on disk is untouched either way, and the myTonies web app remains a working fallback.
